# Contributing to CrawlPNT 🤖🕸️

Thank you for your interest in contributing to **CrawlPNT – Precision Navigation Tool for Dependency-Free, AI-Ready Web Crawling**. Your help makes this project better for everyone, whether you are fixing bugs, suggesting new features, or improving documentation.

## How to Contribute

### Reporting Issues
- **Found a bug or have a feature request?**  
  Please [open an issue](https://github.com/datapnt/crawlpnt/issues) on our GitHub repository. Include a clear description of the problem, steps to reproduce, and any other relevant details.

### Submitting Pull Requests
Pull requests are welcome! Please follow these steps:
1. **Fork the Repository:**  
   Click the "Fork" button at the top-right of the repository page.
2. **Create a New Branch:**  
   Use a descriptive branch name, for example:
   - `feature/initial-setup`
   - `bugfix/issue-123-fix`
3. **Make Your Changes:**  
   - Ensure your code follows our style guidelines (see below).
   - Write tests for new features or bug fixes.
4. **Run Tests:**  
   Verify that all tests pass locally before submitting your pull request. We use GitHub Actions to run our test suite.
5. **Submit a Pull Request:**  
   Include a clear title and description for your changes. Reference any related issues by number.
6. **Participate in the Code Review:**  
   Be open to feedback and ready to make revisions as needed.

### Code Style Guidelines
- **Follow PEP 8:**  
  Write clean, readable code using [PEP 8](https://www.python.org/dev/peps/pep-0008/).
- **Modular and Documented Code:**  
  Keep functions small, and provide clear docstrings.
- **Testing:**  
  Ensure new code is accompanied by tests, and run existing tests before committing.

### Documentation
- Update the **README.md** or any relevant documentation in the **docs/** folder if your changes affect how the project is used.
- Include usage examples or update the **examples/** folder as necessary.

### Community Guidelines
By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). We strive for a friendly, supportive, and constructive community.
