## [0.1.0] - 2025-02-10

### Added
- **Initial Release:**  
  - Introduced the core functionality of CrawlPNT.
  - Implemented rule-based crawling with configurable parameters such as `max_depth`, `target_url`, and `politeness_delay`.
  - Added support for a YAML-based configuration file.
  - Provided multiple output formats: plain text (`.txt`), JSON (`.json`), and CSV (`.csv`).
  - Developed a basic command-line interface (CLI) to run crawls using configuration files.
  - Included initial documentation, examples, and basic unit tests.
